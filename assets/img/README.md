# Images

Drop brand assets here and the homepage will pick them up.

| File | Used for | Notes |
| --- | --- | --- |
| `logo.png` (or `.svg`) | Hero brand mark | The Cruise Ship Karen roundel, gold version. SVG preferred — it stays sharp at any size. |
| `karen.jpg` | Hero portrait | The banner shot: on deck, map shirt, sea behind. A cut-out (transparent PNG) works even better. |

Once the files are here, replace the placeholder blocks in `index.html` —
each one sits directly under a comment showing the `<img>` tag to use.
